🍎 macOS

Installs Node.js if missing, downloads Bucks, and adds an app launcher to ~/Applications.

curl -fsSL https://bucks.global/install | bash

🐧 Linux

Same one-liner. Detects your platform automatically and sets up a launch script in ~/.bucks.

curl -fsSL https://bucks.global/install | bash

🪟 Windows

Run in PowerShell. Installs Bucks to %USERPROFILE%\.bucks and adds a Start Menu shortcut.

irm https://bucks.global/install.ps1 | iex

What's inside

⇄

Offline-first mesh networking

Peer-to-peer discovery and sync that keeps working without a central server.

🔒

End-to-end encrypted messaging

Ed25519-signed, encrypted-at-rest chat between peers on the network.

🧠

Local AI inference

The Soul Engine runs models on-device, sized to your hardware — no API keys, no cloud dependency.

◈

Chain 8192 wallet

A built-in wallet for BUCKS, integrated directly into the browser.

Agentic Interface — v1.1

⚡

Dual-engine intelligence

Local QNN semantic search and NVIDIA NIM cloud reasoning race in parallel per query. QNN wins when quality ≥ 0.65 — NIM overrides silently when it doesn't. Always the best answer, always private-first.

☁

NVIDIA NIM integration

Cloud-grade reasoning via Nemotron 70B, with live token streaming, model selection, and a dedicated NIM execution panel. Transparent quality scoring — you always see which engine answered and why.

🎯

Project NEXUS agent

A goal-driven agent with typed step traces, browser action approval gates, swarm peer topology, and persistent goal history. Invoke with ⌘+Shift+A — think, act, browse, report.

📊

Quality benchmarking

Built-in quality dashboard with sparklines, strategy heat maps, and automated 20-query benchmarks. An RL feedback loop continuously tunes the local engine from every interaction.
